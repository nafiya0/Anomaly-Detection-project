# Dataset

The raw hourly electricity dataset is not included in this repository.

The analysis was run in Google Colab using a CSV-formatted file named `electricity.txt`, stored in Google Drive. Update the notebook's input path to match your own copy.

The dataset contains a timestamp column and individual electricity-meter reading columns. Obtain the dataset from its original provider and follow its licence and attribution requirements before redistribution.

Do not upload private, restricted, or very large raw data files to this repository.
